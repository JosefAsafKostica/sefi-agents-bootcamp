# sefi-agents-bootcamp

המסע שלי בקורס "טירונות סוכנים" של אִימפּרוּב — בנייה אישית של סוכן AI שילווה אותי בקורס ואחריו.

---

## מבנה התיקיות

```
sefi-agents-bootcamp/
├── master-library/           ← הידע שלי (knowledge-about-me, technical-context, וכו')
└── agents/
    ├── in-progress/          ← סוכנים שאני בונה עכשיו
    ├── completed/            ← ארכיון של קבצי פיתוח (אחרי שסוכן הסתיים)
    └── ready/                ← סוכנים פעילים, מוכנים לעבודה יומית
```

---
