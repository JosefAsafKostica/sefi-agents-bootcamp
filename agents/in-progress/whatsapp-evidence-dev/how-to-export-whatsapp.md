# איך לייצא שיחת וואטסאפ לסוכן

> מדריך קצר. הייצוא הוא פונקציה מובנית של וואטסאפ — לגיטימי לחלוטין, בלי אפליקציות חיצוניות.

## מהאייפון

1. פותחים את השיחה (עם איש קשר או קבוצה).
2. לוחצים על **שם איש הקשר / הקבוצה** למעלה.
3. גוללים למטה ובוחרים **"ייצוא צ'אט" (Export Chat)**.
4. בוחרים **"ללא מדיה" (Without Media)** — מפיק קובץ `.txt`.
   - אם יש תמונות/הקלטות מהותיות לתיק — בוחרים **"צירוף מדיה" (Attach Media)**.
5. שולחים את הקובץ לעצמך (מייל / AirDrop למק / שמירה בקבצים).

## מהמק / דפדפן (WhatsApp Web)

הייצוא הנוח ביותר הוא מהטלפון. ב-WhatsApp Desktop אפשר לפעמים דרך תפריט השיחה ← **ייצוא צ'אט**. אם לא זמין — לייצא מהאייפון ולהעביר למק.

## מה עושים עם הקובץ

מעבירים לסוכן את קובץ ה-`.txt` (או מדביקים את התוכן), ואומרים:
- **לאיזה תיק** זה שייך
- **מי הצדדים**
- **מה מחפשים** (הפלוגתא / השאלה המשפטית)

והסוכן מחזיר חומר ראיות מובנה.

## שתי הערות חשובות

- **בלי מדיה** מקבלים קובץ קליל ומהיר, אבל תמונות/הקלטות מסומנות כ־`<מדיה הושמטה>`. אם המדיה עצמה היא הראיה — לייצא **עם** מדיה.
- הייצוא כולל **תאריך ושעה מדויקים** לכל הודעה — זה בדיוק מה שהסוכן צריך כדי לבנות אסמכתאות לכתב הטענות.
