# מפגש 1 — החלטות (סוכן הכספים "כספי")

**תאריך:** 2026-07-26

## מה הוחלט
1. **מהות:** סוכן הכספים של אסף למסעדנות. שלושה זרמים: (A) חשבוניות → דו"ח רווח והפסד פר מסעדה; (B) לוח תשלומים לספקים; (C) טיוטות תלושי שכר.
2. **היקף הבנייה הראשונה:** אסף בחר "הכל — כולל טיוטות תלושים".
3. **שם מוצע:** כספי (שם ישראלי + "של כסף"). טעון אישור.
4. **תלושי שכר — טיוטה בלבד.** בגלל הרגולציה (חוק הגנת השכר, שיעורי מס/ביטוח לאומי משתנים, חשיפה לקנסות ותביעות): כספי מכין טיוטה + חישוב מקדים, ומסמן כל שיעור "לאימות"; חשב שכר מוסמך / תוכנת שכר סוגרים. לא ממציא שיעורים.
5. **הפרדה בין ישויות** — כל מסעדה/חברה נפרדת (עקרון מ-knowledge-about-me).
6. **מיושר ל-skill קיים** `restaurant-pnl-quarterly` — כספי מכין נתונים, ה-skill מפיק דו"ח Word מעוצב. לא בונים מבנה P&L מאפס.
7. **מבצר:** מ = 3 סוגי תוצרים כספיים; ב = 3 זרמים (A/B/C); צ = חשבוניות (PDF/תמונה/Excel) + נתוני עובדים + הפרדה פר מסעדה; ר = מיקוד (איזו מסעדה/תקופה) → עיבוד → תוצר לקובץ → אישור; תלוש = טיוטה + חשב שכר.
