# Knowledge: P&L Method — דו"ח רווח והפסד למסעדה

> שכבת ידע. נכתב במפגש 1 (2026-07-26). מיושר ל-skill `restaurant-pnl-quarterly`.

## מבנה הדו"ח (פר מסעדה, פר תקופה)

| שורה | מה | הצגה |
|------|-----|------|
| הכנסות (Sales) | סך המכירות בתקופה | ₪ |
| עלות חומר גלם (Food Cost) | חומרי גלם, משקאות | ₪ + % מהמכירות |
| עלות שכר (Labor Cost) | שכר, מעביד, קבלני כ"א | ₪ + % |
| **Prime Cost** | Food + Labor | ₪ + % |
| שכירות ותפעול (Occupancy) | שכ"ד, ארנונה, חשמל, מים, גז | ₪ + % |
| הנהלה וכלליות (G&A) | ניהול, שיווק, ביטוח, עמלות | ₪ + % |
| הוצאות מימון | ריבית, עמלות בנק, סליקה | ₪ + % |
| **רווח תפעולי / נקי** | מה שנשאר | ₪ + % |

## Benchmarks לזיהוי חריגות (טווחים כלליים בענף — לא כלל ברזל)

- **Food Cost:** ~28%–35% מהמכירות. מעל 35% = דגל.
- **Labor Cost:** ~25%–35%. תלוי סוג המסעדה.
- **Prime Cost:** יעד מתחת ל-~65%. מעל = הרווחיות נשחקת.
- **Occupancy:** ~8%–12%.

> אלה טווחים להתרעה בלבד. כל מסעדה שונה — להשוות בעיקר לחודשים קודמים של **אותה** מסעדה.

## ניתוח נקודות כשל (מה מוסיפים לכל דו"ח)
- איפה חריגה מול benchmark או מול תקופה קודמת.
- **למה** (אם ניתן לזהות מהנתונים) — למשל עלייה ב-Food Cost בגלל ספק מסוים.
- **המלצה קונקרטית** — מה לבדוק / לתקן.
