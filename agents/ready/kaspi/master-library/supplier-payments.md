# Knowledge: Supplier Payments — לוח תשלומים לספקים

> שכבת ידע. נכתב במפגש 1 (2026-07-26).

## מבנה הטבלה (פר מסעדה)

| שדה | מקור | הערה |
|------|------|------|
| ספק | חשבונית | שם מלא |
| מס' חשבונית | חשבונית | לזיהוי |
| סכום (כולל מע"מ) | חשבונית | ₪ |
| תאריך חשבונית | חשבונית | |
| תנאי תשלום | חשבונית / הסכם | שוטף / שוטף+30 / שוטף+60 וכו' |
| **תאריך יעד לתשלום** | מחושב | מתאריך החשבונית + התנאי |
| סטטוס | קלט אסף | טרם שולם / שולם / חלקי |
| דחיפות | מחושב | ראה למטה |

## לוגיקת דחיפות
- 🔴 **באיחור** — תאריך היעד עבר וטרם שולם.
- 🟠 **דחוף** — תאריך היעד בתוך 7 ימים.
- 🟢 **בהמשך** — מעבר ל-7 ימים.

## חישוב תאריך יעד — "שוטף+N"
"שוטף+30" = סוף החודש של תאריך החשבונית, ועוד 30 יום. אם התנאי לא ברור בחשבונית — לשאול את אסף, לא להניח.

## פלט
- טבלה ממוינת לפי תאריך יעד (הדחוף למעלה).
- **סיכום שבועי:** כמה ₪ לשלם השבוע, לאילו ספקים, ומה באיחור.
- מיועד להעברה לג'ונאם / יומן לתזכורות.

## דגלים
- חשבונית כפולה (אותו ספק, אותו סכום, תאריך קרוב).
- ספק שמופיע לראשונה (לבדוק מול הסכם).
- קפיצה חריגה בסכום מול חשבוניות קודמות מאותו ספק.
